# 모듈 계약

| 호출하는 쪽 | 받는 쪽 | 호출 |
|---|---|---|
| lily-frontend | lily-builder | `POST /api/builds` (클라우드). 내 PC면 `POST /api/agents/{key}/builds`. 상태는 `GET /api/builds/{id}`. `commit`이 40자면 `builder_runs.commit_sha`에 남긴다 |
| lily-frontend | lily-builder | `POST /api/agents`, `GET /api/agents/{key}` |
| lily-frontend | lily-builder | `GET /api/apps/{app}/address`, `POST /api/apps/{app}/home` 본문 `{ home, migrateDatabase: false }` |
| lily-builder | lily-cicd | `POST /api/deployments` |
| lily-builder | lily-cicd | `GET /api/deployments/{app}/progress`, `GET /api/apps/{app}`, `PUT /api/apps/{app}/replicas`, `POST /api/deployments/{app}/rollback` |
| lily-builder | 온프레미스 에이전트 | WebSocket `/api/agents/connect?token=`. 잡은 `type=job`. 롤백은 `type=rollback`, 거점 전환은 `type=home` |
| lily-cicd | lily-db-provisioner | `GET /api/databases?projectId=`, `POST /api/databases`, `GET /api/databases/{id}/env`. `projectId`는 `appName` |
| lily-builder | lily-db-provisioner | `GET /api/databases/{id}/env?host=&port=`. 입구는 `POST /api/burst/apps/{app}/database` |
| lily-on-premise | lily-builder | `POST /api/burst/apps/{app}/standby`, `GET /api/burst/builds/{id}`, `GET /api/burst/apps/{app}`, `PUT /api/burst/apps/{app}/replicas`. 플랫폼 연결이면 같은 method·path를 소켓 `type=burst`로 보낸다 |
| lily-builder 프로세스 | Claude 또는 OpenAI | `AiAdvisor`. 설정 키 분류와 실패 진단. `ANTHROPIC_API_KEY`가 있으면 Claude, 없고 `OPENAI_API_KEY`가 있으면 OpenAI. 둘 다 없으면 호출하지 않고 규칙을 쓴다 |
| lily-observer | lily-frontend | `RemediateWatch`가 `WATCH_INTERVAL`(기본 30초)마다 상태 판정을 한다. CRITICAL이 `JUDGE_CONSECUTIVE`(기본 2)번 연속이고 `observer.remediate.enabled`이면 CloudWatch 최근 15분을 읽어 `POST {REMEDIATE_FRONTEND_URL}/api/internal/remediate`. `POST /api/apps/{app}/remediate`도 같은 전송이다. 롤백은 부르지 않는다 |
| lily-frontend | lily-builder | `POST /api/remediate/drafts`. 배포 커밋의 해당 파일, 가린 로그, 설치 토큰 |
| lily-builder | lily-jev | `lily.remediate.enabled`이고 `JEV_API_KEY`가 있을 때 `POST https://api.typesafe.ai/v1/systemone`. 질문 `code-defect`, 예 확률 0.8 이상만 diff로 간다. 키가 없으면 묻지 않고 코드 결함으로 본다 |
| lily-builder | Groq | `GROQ_API_KEY`가 있으면 `POST https://api.groq.com/openai/v1/chat/completions`, 모델 `openai/gpt-oss-20b`. 없으면 Claude, 그것도 없으면 OpenAI. diff만 돌려주고 GitHub는 호출하지 않는다 |

받는 컨트롤러: `BuildController`, `AgentController`, `DeployController`, `AppController`, `DatabaseController`, `AgentSocket`, `BurstController`, `RemediateController`.

`lily-observer`의 `GET /api/apps/...` 는 선언되어 있다. 이 사본의 다른 모듈에서 그 경로를 호출하는 코드는 없다.
